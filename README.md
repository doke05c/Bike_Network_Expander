# Bike Network Expander

Builds a weighted, directed NYC bike network from the DCP LION GeoPackage and exports it for the
[Bikeable Radius map](https://urbanblogs.netlify.app/posts/nyc_directed_network.html) on UrbanBlogs.

## Run

```
pip install networkx geopandas shapely folium pydeck pandas mapclassify matplotlib
python route_test.py --urbanblogs /path/to/your/UrbanBlogs [--gpkg path/to/LION.gpkg]
```

`--urbanblogs` is required (it differs per machine). The script writes the map data to
`<UrbanBlogs>/src/bike_network/`: the packed network (`network.bin.gz`), its browser decoder, and the vector tiles the
map draws the network from. Commit that directory in UrbanBlogs to publish it.

## What lives where

| Here (Bike_Network_Expander) | UrbanBlogs |
|---|---|
| `route_test.py`: GeoPackage → graph → weights, class colors/widths, legend labels | `posts/nyc_directed_network.html`: the page text, layout and map/UI code (edit it there) |
| `web_export/`: packing (`pack.py`), vector tiles (`tiles.py`), the decoder (`network_format.js`) | `src/bike_network/`: generated by this repo, don't edit by hand |

The page reads these fields from the export: `multipliers, subs, sub_colors, sub_widths, names, legend` and the
per-segment columns `nf, nt, wf, wr, name, sub, coords`. Renaming or removing one needs a matching page change;
adding a new one doesn't. `web_export` uses only the Python standard library.
